# RTL Design and Synthesis Workshop

Welcome to my RTL Design and Synthesis Workshop repository!

This repository documents my learning journey in RTL (Register Transfer Level) Design using **Verilog HDL** and open-source EDA (Electronic Design Automation) tools. It contains theory, practical implementations, simulation results, synthesis reports, and notes from each workshop session.

The objective of this repository is to build a strong foundation in digital design and ASIC front-end design while learning industry-standard design flow using open-source tools.

---

## Objectives

- Learn Verilog HDL for digital circuit design.
- Understand the RTL design flow.
- Perform functional simulation using Icarus Verilog.
- Analyze waveforms using GTKWave.
- Synthesize RTL using Yosys.
- Map RTL designs to the Sky130 standard cell library.
- Document concepts and practical implementations for future reference.
